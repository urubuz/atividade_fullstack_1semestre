## 📁 Atividade Principal

A pasta **`atividade-principal`** contém um portfólio onde se encontram várias páginas com funcionalidades diferentes, como:

* Um jogo de adivinhação
* Uma animação usando o Canvas
* Um formulário

## 📝 Provas

Nas pastas **`p1oficial`** e **`p1simulado`** se encontram o meu simulado e minha prova oficial do semestre, onde tive que copiar um site de forma idêntica.

---

## 🖥️ Servidor

Para poder testar o formulário da aula 8, na atividade principal, deve-se estar ligado a um servidor.

É para isso que existe o **`Servidor.zip`**.

No entanto, o servidor deve estar sendo hospedado em algum computador, e no momento não está.
